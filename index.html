1.1.0 更新

  • LibTV 镜头生成：用自己的账户检查模型、主动启用，确认内容与费用后生成；结果先进入候选，显式采用后再剪辑和导出。
  • 候选与恢复：改进同一项目连续生成的默认节点命名；已有结果可继续查询、下载或导入，不重复提交付费生成。
  • 编辑体验：保留已有配音和片段时长，改进剪辑恢复、撤销重做与报错展示。
  • Public 3D：使用程序化胶囊体作为角色占位，支持基础场景编辑；不提供骨骼姿态或关节手柄编辑。

安装与安全提示

只从本页或 GitHub Release 下载 Public 包。Internal 与 Beta 包不对外分发。请在下载后核对本页显示的 SHA-256。

试用须知

  • Public 版无需邀请码或激活码；首次启动后可配置自己的模型 API Key。
  • Public 版不内嵌模型凭证，也不提供托管的模型额度或内部通道。
  • 云端模型可能产生由对应服务商收取的费用。
