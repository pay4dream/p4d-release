从安装、参考到静态与动态 KV

← 回下载页

发布状态

Pay4Dream Public 1.1.2 的 macOS Apple Silicon 与 Windows x64 安装包已通过公开 Release 提供。macOS 使用 ad-hoc 签名、尚未公证；Windows 安装包未签名，本版不声称已完成 Windows 实机验收。

1. 安装

  • macOS：核对下载页的文件名与 SHA256，打开 .dmg，把 Pay4Dream Public 拖进「应用程序」。应用尚未公证；首次打开可右键图标选择「打开」，仍被拦截时查看「系统设置 → 隐私与安全性」。不要全局关闭 Gatekeeper。
  • Windows：双击 .exe 走安装向导。SmartScreen 出现提示时可选择「更多信息」→「仍要运行」。安装包未签名；本版不声称已完成真实 Windows 机器上的安装启动验收。

2. 首次启动

Public 版打开应用后可以直接建立项目，或先进入设置配置模型服务。

3. 配置自己的模型服务

本版需要自带模型服务。进入设置 → 供应商填写自己的服务信息，再到设置 → AI 引擎为不同任务选择模型。

  • 服务信息只保存在本机，请求发往你选择的模型服务商。
  • 没有可用模型时，请先到对应服务商取得访问权限并完成配置。
  • 云端模型可能产生由对应服务商收取的费用；每次付费生成前都应核对应用内提示。

4. 从项目到成片

  1. 新建项目；已有文案、链接或文件时，可先用「对话生成」整理项目、序列和镜头。
  2. 有现成图片、视频或音频时先导入资产库，再绑定到目标镜头。
  3. 常用逐镜头操作留在「生成」模式；需要节点、上下游关系和执行计划时切到「流程」。
  4. 需要安排角色占位、场景、摄影机或参考时，可打开当前镜头的「3D 分镜」编辑场景。Public 版使用程序化胶囊体作为角色占位，支持基础场景编辑；不提供骨骼姿态或关节手柄编辑。
  5. 提交前检查提示词、参考素材和参数；只有确认提交后才会运行生成。结果可在项目里预览、选片、重试并进入自动剪辑。

5. KV 创作：第五工作区

「KV 创作」与图片生成、3D 分镜、视频生成、剪辑并列，适合把角色、主体、场景、构图和风格组合成完整主视觉参考。它共享当前项目、素材库、任务与模型，不另建一套资产或渲染系统。

  1. 进入「KV 创作」，在角色/主体、场景、构图、风格四个区域选择已有素材，或补一句清楚的画面需求。人数、景别和横竖版使用简单选项；缺图或超过当前模型参考上限时，界面会明确提示。
  2. 点「生成静态 KV」后先核对标题、模型、实际尺寸、引用数量与费用。确认只授权当前这一次提交，确认后再生成。
  3. 生成完成后可并排比较上一稿与当前稿；重用上一稿的参考，换角色、场景或要求即可继续做变体。

5.1 3D 构图往返

在构图中选择进入 3D 后，可调整角色、场景与机位。3D 工作区捕获的结果会写回同一份 KV 草稿；返回后继续使用真实当前机位，已选的角色、场景和风格不会被清空。打开 3D 构图和捕获本身不会提交付费生成。

5.2 一键动态 KV

  1. 选中一张已生成的静态 KV，点「一键动态KV」。静态图会直接作为图生视频首帧，并自动关联当前 KV 草稿；不需要另建序列或镜头。
  2. 选择「人物微动」「环境氛围」或「缓慢运镜」，也可以补充一句想要的运动。默认建议保持主体、身份、服装、光线和构图，运动幅度克制。
  3. 查看模型实际支持的范围与费用，再做一次明确确认。确认后只提交一次；静态原图不会被覆盖。
  4. 动态结果会回到同一张 KV 卡，可播放、换一个动态方向，或送入后续剪辑。失败或结果未知时不要立即重复提交，先到任务历史和资产库核对。

动态 KV 是创意参考：重点是人物轻动作、环境氛围与克制运镜，不承诺无缝循环、逐像素不变、口型、对白、配音、音乐或自动成片。

6. 本机会话工具与桌面 Agent API

安装包内含 p4d-cli、别名 p4d、版本清单与 P4D_CLI.md。macOS 可在 Pay4Dream Public.app/Contents/Resources/ 找到客户端；Windows 可在应用安装目录找到 p4d-cli.exe 与 p4d.exe。安装不会自动把它加入 PATH。

这套工具供 Agent 和脚本通过本机会话操作正在运行的桌面应用。它可以发现会话、读取状态与命令目录、查询项目，并请求应用执行允许的结构或界面操作；结果展示、KV 草稿、费用确认和可视化仍由 Pay4Dream 处理，不是第二个引擎或数据库。

也可以直接阅读 1.1.2 命令行完整说明。

  1. 先启动同一版本的 Pay4Dream 桌面应用，再用客户端所在路径执行 p4d-cli guide，查看当前版本自带的使用说明。
  2. 执行 p4d-cli sessions 和 p4d-cli status，确认存在可用本机会话且应用版本完全一致。没有会话或版本不一致时，客户端会在提交前停止。
  3. 用 p4d-cli commands 查看允许的命令、参数和风险类型；用 p4d-cli ui open 请求打开已有界面，不创建另一套可视化。
  4. 若请求超时或连接中断，先用 p4d-cli request-status <请求编号> 查询，或到任务历史与资产库核对。不要自动重投可能已经执行的付费、破坏性或敏感请求。

收费确认与安全边界：命令行中的付费、破坏性、敏感许可只是附加护栏，不会绕过应用内确认。KV 的生成请求只能打开应用内费用确认，不能由命令行直接扣费；反馈提交也只由用户在桌面界面确认。会话只接受本机认证连接，令牌不会打印在输出或错误信息中；不要把模型服务密钥写入命令行、共享脚本或反馈内容。需要传递敏感输入时，使用权限受限的本机文件或标准输入。

7. 常见问题

  • 提示服务不可用或额度不足：到对应模型服务商后台确认访问状态和余额。
  • 打不开或被系统拦：见第 1 步的右键打开与 SmartScreen 放行说明。
  • 生成很慢或失败：先检查网络能否访问对应模型服务商；已有任务可从任务历史恢复，不要自动重复提交付费请求。
  • 动态 KV 结果未知：保留请求编号，先查询任务状态和资产库，确认没有结果后再显式重开一次生成。
  • 命令行找不到会话：确认桌面应用正在运行、客户端与应用版本一致，并查看 p4d-cli sessions 的结果。
