从安装到生成第一条成片

发布状态

macOS Apple Silicon 与 Windows x64 Public 1.1.0 均已发布。请从下载页按系统选择并核对 SHA256；Windows 未签名，未进行实机验收。历史图片与视频保留原版本标注。

1. 安装

  • macOS：核对下载页的文件名与 SHA256，打开 .dmg，把 Pay4Dream Public 拖进「应用程序」。 应用使用 ad-hoc 签名，尚未公证。首次打开按系统提示右键图标 → 打开；仍被拦截时查看「系统设置 → 隐私与安全性」。不要全局关闭 Gatekeeper。
  • Windows：双击 .exe 走安装向导。SmartScreen 弹窗点 「更多信息」→「仍要运行」。安装包未签名；本版尚未完成真实 Windows 机器上的安装启动验收。

2. 首次启动

Public 版无需邀请码或激活码。打开应用后直接建立项目，或先进入设置配置模型服务。

3. 填入你自己的 API Key

本版需要你自带模型 Key。进入设置 → Providers 填入对应供应商 Key； 再到设置 → AI 引擎为不同任务选择模型。

  • LLM 可选 Claude / GPT / Gemini / Grok / OpenRouter / DeepSeek / Kimi / Qwen / GLM / MiniMax / 自定义 OpenAI-compatible。
  • Key 只保存在本机，请求直接发往对应模型厂商，不经第三方中转。
  • 没有 Key？到对应模型厂商官网申请后再回来填。

4. 生成第一条成片

  • 新建项目；已有文案、KM、链接或文件时，先用「对话生成」整理项目、序列和镜头。
  • 有现成图片、视频或音频时先导入资产库，再绑定到目标镜头。
  • 常用逐镜头操作留在「生成」模式；需要节点、上下游关系和执行计划时切到「流程」。
  • 需要安排角色占位、场景、摄影机或参考时，可打开当前镜头的「3D 分镜」编辑场景。Public 版使用程序化胶囊体作为角色占位，支持基础场景编辑；不提供骨骼姿态或关节手柄编辑。
  • 在 3D 分镜中可选择场景对象，使用移动、旋转、缩放控件编辑；操作支持撤销、重做和保存恢复。
  • 提交前检查 prompt、参考素材和参数；只有确认提交后才会运行生成。
  • 生成结果可在项目里预览、选片、重试并进入自动剪辑。

4.1 用自己的 LibTV 账户生成镜头

以下步骤已在 macOS Public 1.1.0 完成必要操作验证；Windows 实机操作未验收。

  1. 打开「设置 → 集成 → LibTV 外部生成」。自行安装官方 CLI、登录自己的账户，点「检查账号与模型」，确认可用后主动启用；检查和启用不会自动生成。
  2. 选中目标镜头，点镜头底部「LibTV」，选择画布项目并检查 Seedance 2.5、提示词、时长与可用参数。
  3. 点「生成命令预览」核对信息，再阅读费用提示并点「确认生成」。提交后不要重复发起同一个付费任务。
  4. 结果进入候选后先预览；在「提交记录」点「选为成片」，确认「已选定」，再进入剪辑与导出。预览本身不会替换成片。
  5. 下载或导入中断时，从原镜头的「LibTV 恢复」继续已有任务；恢复不会重新提交生成，关闭集成也不删除既有恢复记录。

账户、会员与凭据不随包提供。历史带水印素材不会自动替换；新下载以账户权益和平台返回结果为准。1080p 导出不等于原始生成就是 1080p。Dreamina 生成、Higgsfield 与新的移动端交付不在本次范围内。

5. 参考素材与外部生成

  • SceneBoard 可导入本地图片 / 视频、Cadrage 和移动端采集素材；导入、编辑和预览不会自动生成。
  • Android 镜头捕捉器技术预览可采集镜头运动并回传 .p4dcapture；尚未完成真实设备硬件验收。iOS 上线时间未定。
  • iOS 文件通过系统 Files / File Provider 已同步到本机的目录读取，P4D 不提供自有 iCloud 账号绑定。
  • LibTV 是可选第三方集成，需要自行安装官方 CLI 并显式登录；镜头生成需「确认生成」，既有外部生成入口需「确认上传并生成」，确认后才会运行相应任务。

6. 常见问题

  • 提示 Key 无效 / 额度不足：到模型厂商后台确认 Key 状态和余额。
  • 打不开 / 被系统拦：见第 1 步的右键打开 / SmartScreen 放行。
  • 生成很慢或失败：检查网络能否访问对应模型厂商，稍后重试。
