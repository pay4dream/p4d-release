1. 安装

  • macOS：打开下载的 .dmg，把 Pay4Dream 拖进「应用程序」。 首次打开右键图标 → 打开，弹窗里再点「打开」。若提示「已损坏」， 终端运行 xattr -dr com.apple.quarantine "/Applications/Pay4Dream.app" 后重试。
  • Windows：双击 .exe 走安装向导。SmartScreen 弹窗点 「更多信息」→「仍要运行」。

2. 首次启动：输入邀请码

第一次打开会要求输入邀请码。把拿到的邀请码粘进去激活即可。 如果还没有邀请码，请邮件联系 pay4dream.app@gmail.com 获取。 激活信息保存在本机，下次启动不再要求。

3. 填入你自己的 API Key

本版需要你自带模型 Key。进入设置 → Providers 填入对应供应商 Key； 再到设置 → AI 引擎为不同任务选择模型。

  • LLM 可选 Claude / GPT / Gemini / Grok / OpenRouter / DeepSeek / Kimi / Qwen / GLM / MiniMax / 自定义 OpenAI-compatible。
  • Key 只保存在本机，请求直接发往对应模型厂商，不经第三方中转。
  • 没有 Key？到对应模型厂商官网申请后再回来填。

4. 生成第一条成片

  • 新建项目；已有文案、KM、链接或文件时，先用「对话生成」整理项目、序列和镜头。
  • 有现成图片、视频或音频时先导入资产库，再绑定到目标镜头。
  • 常用逐镜头操作留在「生成」模式；需要节点、上下游关系和执行计划时切到「流程」。
  • 修正版上线后，要控制角色、场景、姿态、摄影机或动态参考时，打开当前镜头的「3D 分镜」编辑 SceneBoard。
  • 提交前检查 prompt、参考素材和参数；只有确认提交后才会运行生成。
  • 生成结果可在项目里预览、选片、重试并进入自动剪辑。

5. 参考素材与外部生成

  • 修正版目标：SceneBoard 可导入本地图片 / 视频、Cadrage 和移动端采集素材；导入、编辑和预览不会自动生成。
  • 镜头运动轨迹联动计划 Android 优先；iOS 上线时间未定，两者均未包含在当前 1.0.0 中。
  • iOS 文件通过系统 Files / File Provider 已同步到本机的目录读取，P4D 不提供自有 iCloud 账号绑定。
  • LibTV 是可选第三方集成，需要自行安装官方 CLI 并显式登录；只有「确认上传并生成」会运行外部任务。

6. 常见问题

  • 提示 Key 无效 / 额度不足：到模型厂商后台确认 Key 状态和余额。
  • 打不开 / 被系统拦：见第 1 步的右键打开 / SmartScreen 放行。
  • 生成很慢或失败：检查网络能否访问对应模型厂商，稍后重试。

7. 反馈

问题和建议优先在 App 内打开 AI 助手 描述；如果 App 无法打开， 请邮件联系 pay4dream.app@gmail.com。 反馈时请附系统版本、App 版本、复现步骤和截图。
